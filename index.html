Deep Learning & Vision

Explainable Wildfire Segmentation (PEP Project)

IoU: 0.8009 • Dice: 0.8891

A deep learning framework for aerial wildfire image segmentation and visual interpretability. Evaluated multiple semantic segmentation architectures on the FLAME aerial dataset with Grad-CAM and SmolVLM-500M explainability.

Python PyTorch U-Net++ SegFormer Grad-CAM SmolVLM-500M
Repository (Placeholder) Project Demo

Problem Statement & Objective

Problem: Rapidly spreading wildfires demand instant, pixel-accurate localization from aerial surveillance drones. Conventional thresholding techniques struggle with varied smoke densities, illumination shifts, and thermal noise.

Objective: Benchmark advanced encoder-decoder segmentation architectures on aerial flame imagery to maximize IoU/Dice overlap while providing visual explainability through feature heatmaps and vision-language reasoning.

Verified Results & Evaluation Metrics

  • Dataset: FLAME Wildfire Dataset (2,003 image-mask pairs)
  • Architectures Compared: U-Net, U-Net++, Attention U-Net, SegFormer, DeepLabV3+
  • Top Performing Model: U-Net++ with geometric & photometric augmentations
  • Test IoU: 0.8009 (80.09% Intersection over Union)
  • Dice Coefficient: 0.8891 (88.91% Dice score)
  • Explainability: Grad-CAM feature attribution + SmolVLM-500M multimodal visual captions

Implementation Workflow

01
Data Ingestion & Augmentation: Cleaned 2,003 aerial image-mask pairs from the FLAME dataset; applied spatial rotations, color jittering, and elastic transformations to address class imbalance.
02
Model Training & Benchmarking: Trained U-Net, U-Net++, Attention U-Net, SegFormer, and DeepLabV3+ backbones in PyTorch using compound Focal-Dice loss functions.
03
Explainability Pipeline: Integrated Grad-CAM to visualize neural attention on flame boundaries, and deployed SmolVLM-500M to generate automated situational reports of burn perimeter severity.

Challenges & Learning Outcomes

Resolving extreme pixel imbalance between background terrain and active fire fronts required tuning dynamic weighting in compound loss functions. Verified how dense nested skip pathways in U-Net++ capture subtle edge gradients significantly better than standard U-Net.

Medical AI & Imaging

Brain Tumor Detection using MRI

Clinical Preprocessing Pipeline

Medical image preprocessing and brain tumor detection using deep convolutional neural networks. Implemented contrast enhancement and radiological feature extraction from neuroimaging scans.

Python TensorFlow scikit-learn OpenCV CNNs MRI (DICOM / NIfTI)
Repository (Placeholder) Project Demo

Problem Statement & Objective

Problem: Accurate identification of neurological tumors in MRI requires meticulous examination of high-dimensional slices. Inconsistent contrast levels and skull boundary artifacts often complicate manual radiological workflows.

Objective: Engineer an automated CNN-based classification pipeline with robust medical preprocessing to detect tumor-positive MRI scans with high diagnostic reliability.

Evaluation & Validation Status

  • Imaging Modalities: Multi-planar Brain MRI (DICOM & NIfTI format slices)
  • Preprocessing: OpenCV skull-stripping, morphological noise filtering & adaptive histogram equalization
  • Network Architecture: Multi-layer CNN with Batch Normalization & Dropout regularization
  • Evaluation Status: Model validation conducted on held-out test splits; formal multi-hospital clinical benchmark pending release.

Implementation Workflow

01
Medical Image Preprocessing: Normalized slice pixel intensities, removed non-brain tissue (skull stripping), and applied CLAHE to highlight fine tissue density contrasts.
02
CNN Training: Configured convolutional feature extractor with ReLU activations, pooling layers, and dropout in TensorFlow to mitigate overfitting.
03
Diagnostic Scoring: Generated probability confidence scores and classification matrices using scikit-learn metrics for evaluation.

Challenges & Learning Outcomes

Mitigating cross-machine scanner artifacts required standardized min-max normalization. Deepened understanding of medical imaging data standards (DICOM metadata parsing and volumetric slice alignment).

MCP Browser Debug Server

Internship Project • Altosyn Technologies

An extensible browser automation and diagnostic debugging server built on the Model Context Protocol (MCP). Empowers LLM agents with real-time browser session control, DOM inspection, screenshot/video capture, and network telemetry.

Python MCP (Model Context Protocol) FastMCP Playwright GitHub

Problem Statement & Objective

Problem: AI coding assistants lack direct execution feedback and runtime inspection when troubleshooting complex, single-page web applications, forcing manual reproduction of visual, network, and console errors.

Objective: Develop an extensible Model Context Protocol (MCP) server that grants AI agents standardized tools to drive headless browsers, capture DOM snapshots, monitor network calls, and record diagnostic artifacts.

Engineering Highlights & Scope

  • Context: Developed during AI Engineering Internship at Altosyn Technologies Pvt. Ltd. (Dec 2025 - Jan 2026)
  • Tools Implemented: Browser session management, UI interaction, DOM inspection, screenshot & video capture, console log analysis, and performance monitoring
  • Diagnostic Telemetry: Automatic runtime artifact recording, responsive viewport emulation, and network waterfall analysis

Implementation Workflow

01
MCP Tool Architecture: Designed FastMCP Python endpoints adhering to the Model Context Protocol specification for tools, resources, and error handling.
02
Playwright Automation Integration: Connected MCP endpoints to Playwright browser instances, orchestrating session cookies, page navigations, click/type events, and DOM tree serializations.
03
Automated Telemetry Capture: Built asynchronous event handlers capturing uncaught JavaScript exceptions, network response codes, and step-by-step video replays for automated debugging.

Challenges & Learning Outcomes

Minimizing payload size when sending serialized DOM trees to LLMs without omitting critical selectors required intelligent tree pruning. Mastered the Model Context Protocol ecosystem, asynchronous Python programming, and production-grade Playwright orchestration.
